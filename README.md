# Loan Approval Prediction

A **Machine Learning-based Loan Approval Prediction System** that predicts whether a loan application is likely to be **Approved or Rejected** based on applicant, financial, credit, and property-related information.

###  Technologies

* Python
* Pandas & NumPy
* Scikit-learn
* Matplotlib & Seaborn
* Joblib
* Tkinter

###  ML Models

* Logistic Regression
* Decision Tree
* Random Forest
* Naive Bayes
* Support Vector Machine (SVM)

###  Features

* Loan approval prediction
* Multiple ML model comparison
* Data preprocessing and visualization
* Approval probability prediction
* Confusion matrix and performance analysis
* Tkinter-based GUI

###  Input Features

* Gender
* Marital Status
* Dependents
* Education
* Self Employment
* Applicant Income
* Coapplicant Income
* Loan Amount
* Loan Term
* Credit History
* Property Area

###  Run

```bash
pip install pandas numpy scikit-learn matplotlib seaborn joblib
python src/loan_gui.py
```
